## 日报方法

1. 优先引用公司官方页面、投资者关系材料、产业研究机构与可信媒体。
2. 区分已披露事实、供应链传闻和分析判断，并标注可信度。
3. 每日输出结论、关键变化、产业影响、风险和下一步跟踪清单。
4. 复用 [`templates/daily-report-template.md`](templates/daily-report-template.md) 保持格式一致。
